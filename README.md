# Roast & Hearth — Sell-Ready Cafe & Restaurant Website

A modern, responsive, zero-build-step interactive website template for cafes, bakeries, and restaurants.

## Features
- **Interactive Menu** with category tabs, Veg-only filter, and live search
- **Slide-out Order Cart** with automatic GST calculation and **Order via WhatsApp**
- **Table Reservation Form** with interactive time slots and instant confirmation
- **Easy Client Customization** via `CAFE_CONFIG` at the top of `app.js`

## Quick Customization for Clients
1. Open `app.js` and update `CAFE_CONFIG` (cafe name, WhatsApp number, currency, GST rate) and `MENU_ITEMS`.
2. Open `index.html` to update the address, opening hours, and contact email.
3. Deploy directly to **GitHub Pages**, **Vercel**, or **Netlify**.
